## 활용 방법

1. 챕터 내용을 읽고 실습을 완료한 뒤 퀴즈를 푼다
2. 정답을 보기 전에 스스로 답을 써본다
3. 틀린 문제는 해당 챕터로 돌아가서 다시 확인한다
4. 모르는 개념이 생기면 `/qna` 로 질문하고 기록한다
