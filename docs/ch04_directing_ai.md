# Ch04 — Claude에게 잘 지시하는 법

> 이 챕터가 커리큘럼 전체에서 가장 중요하다.
> Claude가 코드를 짜지만, **무엇을 만들지 설계하고 결과를 검증하는 것**은 개발자인 당신이 한다.

---

## 개념

### 좋은 요청 vs 나쁜 요청

| 나쁜 요청 | 좋은 요청 |
|----------|----------|
| "플레이어 만들어줘" | "Godot 4에서 WASD로 이동하고 Space로 점프하는 3인칭 CharacterBody3D 플레이어를 만들어줘. 이동 속도 5, 점프력 8이고 중력은 Godot 기본값 사용해줘." |
| "에러 났어" | "이 에러가 났어: [에러 전체 붙여넣기]. 현재 씬 구조는 이렇고: Player(CharacterBody3D) > MeshInstance3D, CollisionShape3D, Camera3D" |
| "더 좋게 만들어줘" | "플레이어가 이동할 때 카메라가 너무 딱딱하게 따라와. 카메라가 부드럽게 보간(lerp)해서 따라오게 수정해줘." |

### 요청 템플릿

**새 기능 요청:**
```
Godot 4에서 [기능]을 만들어줘.
- 씬 구조: [현재 노드 트리 설명]
- 동작: [어떻게 동작해야 하는지]
- 파라미터: [속도, 크기, 횟수 등 수치]
- 파일 위치: res://scenes/[파일명].tscn, res://scripts/[파일명].gd
```

**에러 수정 요청:**
```
Godot 4 에러가 났어:
[에러 메시지 전체 붙여넣기]

현재 파일 구조:
- 씬: [파일명]
- 스크립트: [파일명]
- 노드 트리: [씬 패널에서 본 구조]

직접 파일을 수정해줘.
```

**동작 수정 요청:**
```
현재: [현재 동작 설명]
원하는 것: [바꾸고 싶은 동작]
관련 파일: res://scripts/[파일명].gd

파일을 직접 수정해줘.
```

### Claude가 직접 할 수 있는 것 vs 에디터에서 해야 하는 것

**Claude가 직접 파일 작성/수정:**
- `.gd` 스크립트 파일
- `.tscn` 씬 파일 (노드 구조, 스크립트 연결)
- `project.godot` 입력 설정 (InputMap)
- 폴더 구조 생성

**에디터에서만 가능한 것:**
- `.glb` 3D 모델 임포트 설정
- 애니메이션 키프레임 직접 편집
- 노드 위치 마우스로 미세 조정
- 실행 (F5/F6)

---

## 현재 프로젝트 상태 공유 방법

Claude에게 현재 상태를 전달할 때 유용한 것들:

**씬 구조 공유:** Godot 에디터 씬 패널에서 노드 트리를 텍스트로 설명
```
예: "씬 패널에 이렇게 되어있어:
World (Node3D)
├── DirectionalLight3D
├── Ground (StaticBody3D)
└── Player (CharacterBody3D)
    ├── MeshInstance3D
    └── Camera3D"
```

**에러 공유:** Output 탭의 빨간 텍스트 전체 복사

## 실습: 요청 연습

### 실습 4-1: 기본 씬 요청
다음 요청을 Claude에게 그대로 보내서 프로젝트를 만들어본다:

> "Godot 4 프로젝트에 기본 3D 씬을 만들어줘.
> - `res://scenes/world.tscn` 파일로 저장
> - 회색 바닥 (StaticBody3D + MeshInstance3D 10x1x10 박스 + CollisionShape3D)
> - 하늘색 큐브 (MeshInstance3D 1x1x1, 바닥 위 y=1 위치)
> - 태양광 (DirectionalLight3D)
> - 카메라 (Camera3D, 위에서 45도 각도로 씬을 내려다보는 위치)
> project.godot의 메인 씬도 이걸로 설정해줘."

Claude가 파일을 만들면 → F5로 실행 → 결과 확인
