# Ch01 — Godot 에디터 & 프로젝트 구조

> Godot 에디터는 처음 열면 패널이 많아서 복잡해 보이지만,
> 실제로 자주 쓰는 것은 4~5개뿐이다. 먼저 각 패널의 역할을 이해하는 것에서 시작한다.

---

## 개념

### 에디터 레이아웃 전체 구조

```
┌─────────────────────────────────────────────────────────────┐
│  메뉴바 (Project/Scene/Debug...)  [2D] [3D] [Script] [Game] │
│  툴바 (이동/회전/크기 도구)                                  │
├─────────────┬──────────────────────────┬────────────────────┤
│             │                          │                    │
│  씬 패널    │     뷰포트 (3D/2D)       │  인스펙터          │
│ (노드 트리) │                          │  (속성 편집)       │
│             │   ← 여기서 게임 씬을     │                    │
│ 왼쪽 상단   │     직접 확인/조작       │  오른쪽            │
│             │                          │                    │
├─────────────┴──────────────────────────┴────────────────────┤
│  파일시스템 (res://)  │  출력 콘솔  │  디버거             │
└─────────────────────────────────────────────────────────────┘
```

---

### 각 패널 역할 상세

#### 씬 패널 (Scene Panel) — 왼쪽 상단
게임을 구성하는 노드들의 **계층 구조(트리)**를 보여준다.
마치 폴더 안에 폴더가 있고 그 안에 파일이 있는 구조와 같다.

```
World (Node3D)              ← 루트(최상위) 노드
├── DirectionalLight3D      ← 자식 노드
├── Ground (StaticBody3D)   ← 자식 노드
│   ├── MeshInstance3D      ← Ground의 자식
│   └── CollisionShape3D    ← Ground의 자식
└── Player                  ← 자식 노드
```

- 노드를 클릭하면 인스펙터에 속성이 표시된다
- 눈 아이콘: 뷰포트에서 보이기/숨기기
- 자물쇠 아이콘: 선택 잠금 (실수로 이동 방지)

#### 뷰포트 (Viewport) — 중앙
씬을 3D로 확인하고 노드를 직접 배치하는 공간.

**3D 뷰포트 조작법:**
| 동작 | 방법 |
|------|------|
| 회전 | 마우스 가운데 버튼 + 드래그 |
| 이동 | Shift + 마우스 가운데 버튼 + 드래그 |
| 줌 | 마우스 휠 |
| 노드 이동 | W 눌러 이동 핸들 → 축 드래그 |
| 포커스 | F (선택한 노드를 뷰포트 중앙으로) |

#### 인스펙터 (Inspector) — 오른쪽
선택한 노드의 **모든 속성**을 편집하는 곳.
`@export` 변수도 여기서 Inspector에 표시된다.

```
예: Camera3D 선택 시 Inspector에 표시되는 것들
- FOV: 75         ← 시야각
- Near: 0.05      ← 클리핑 시작 거리
- Far: 4000       ← 클리핑 종료 거리
```

#### 파일시스템 (FileSystem) — 하단 왼쪽
`res://` 아래의 프로젝트 파일들을 탐색하는 창.
`.tscn`, `.gd`, `.glb` 등 모든 파일이 여기 보인다.

#### 출력 콘솔 (Output) — 하단 중앙
`print()` 결과와 **에러 메시지**가 출력된다.
**에러가 나면 가장 먼저 확인해야 하는 곳.**

---

### 핵심 용어

| 용어 | 설명 | 비유 |
|------|------|------|
| **Scene** | 게임 오브젝트들의 묶음. `.tscn` 파일 | 영화의 한 장면 |
| **Node** | Scene을 구성하는 최소 단위. 모든 것이 Node | 레고 블록 하나 |
| **Inspector** | 선택한 Node의 속성을 편집하는 패널 | 사물의 설정 창 |
| **res://** | 프로젝트 루트를 가리키는 Godot 경로 | 프로젝트의 집 주소 |
| **user://** | 사용자 데이터 저장 폴더 (세이브 파일 등) | 사용자 문서 폴더 |
| **F5** | 프로젝트 메인 씬 실행 | 완성된 게임 실행 |
| **F6** | 현재 열려있는 씬만 실행 | 이 씬만 테스트 |

---

### 자주 쓰는 단축키

| 단축키 | 동작 |
|--------|------|
| `F5` | 프로젝트 전체 실행 |
| `F6` | 현재 씬 실행 |
| `Ctrl+S` | 현재 씬 저장 |
| `Ctrl+Z` | 실행 취소 |
| `Ctrl+Shift+Z` | 다시 실행 |
| `Ctrl+D` | 노드 복제 |
| `Del` | 선택한 노드 삭제 |
| `W` / `E` / `R` | 이동 / 회전 / 크기 조절 도구 |
| `F` | 선택한 노드에 포커스 |

---

### 에러가 났을 때

에디터 하단 **Output** 탭에 빨간 에러 메시지가 표시된다.

```
예시 에러:
E 0:00:01:0342   player.gd:15 @ _ready():
  Node not found: "Camera" in path "."
  │              │          │
  └── 파일명     └── 줄번호  └── 함수명
```

**에러 해석 방법:**
- `player.gd:15` → `scripts/player.gd` 파일 15번째 줄에서 발생
- `Node not found: "Camera"` → "Camera"라는 이름의 노드가 없음
- `in path "."` → 현재 노드(`.`) 아래에서 찾다가 실패

**해결 방법:** 에러 메시지 전체를 복사해서 Claude에게 전달하면 된다.
Claude가 정확히 어떤 파일을 어떻게 수정할지 알려줄 것이다.

### 프로젝트 파일 구조

Claude가 앞으로 파일을 이 구조에 맞게 생성한다.

```
res://                          ← 프로젝트 루트
├── scenes/                     ← .tscn 씬 파일들
│   ├── world.tscn              ← 메인 씬
│   ├── player.tscn             ← 플레이어 씬
│   └── ui/                     ← UI 씬들
├── scripts/                    ← .gd 스크립트 파일들
│   ├── player.gd
│   └── game_manager.gd
├── assets/                     ← 3D 모델, 텍스처, 오디오
│   ├── models/
│   ├── textures/
│   └── audio/
├── docs/                       ← 지금 읽고 있는 파일들
└── project.godot               ← 프로젝트 설정 (Claude가 직접 수정)
```

**`project.godot`이 하는 일:**
- 게임 이름, 아이콘, 해상도 설정
- 메인 씬 지정 (F5로 실행될 씬)
- 입력 설정 (어떤 키가 'jump'인지 등)
- Autoload 스크립트 등록
- 물리 엔진 설정

---

### Godot의 두 가지 실행 모드

**F5 — 전체 프로젝트 실행:**
- `project.godot`에 지정된 메인 씬부터 실행
- 실제 게임처럼 처음부터 실행
- 씬 전환, 메인 메뉴 등 전체 흐름 테스트 시 사용

**F6 — 현재 씬 실행:**
- 에디터에서 현재 열려있는 씬만 실행
- 특정 씬만 빠르게 테스트할 때 사용
- 예: 전투 씬만 열어서 전투 테스트

## 실습

### 실습 1-1: 에디터 패널 탐색
Godot 에디터를 열고 다음을 직접 확인한다:
1. 씬 패널이 왼쪽 상단에 있는지 확인
2. Output 탭(하단 중앙)을 클릭해서 콘솔 확인
3. FileSystem 탭에서 `scenes/`, `scripts/` 폴더가 보이는지 확인
   - 없으면: FileSystem 탭에서 우클릭 → New Folder로 생성

### 실습 1-2: F5/F6 차이 확인
Claude에게 기본 3D 씬을 만들어달라고 요청한 후:
1. F6으로 실행 → 현재 씬만 실행됨
2. 다른 씬을 에디터에서 열고 F5 → 메인 씬이 실행됨
3. 차이를 직접 확인

### 실습 1-3: 에러 메시지 복사 연습
Claude에게 의도적으로 에러가 나는 코드를 요청해보거나,
실제 에러가 났을 때 Output 탭에서 빨간 텍스트 전체를 Ctrl+A → Ctrl+C로 복사한다.
