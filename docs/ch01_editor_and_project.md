# Ch01 — Godot 에디터 & 프로젝트 구조

---

## 개념

### 에디터 레이아웃
```
┌─────────────────────────────────────────────────────┐
│  메뉴바 / 툴바                    [2D] [3D] [Script] │
├────────────┬────────────────────────┬───────────────┤
│            │                        │               │
│  씬 패널   │    뷰포트 (3D/2D)      │  인스펙터     │
│ (노드 트리)│                        │  (속성 편집)  │
│            │                        │               │
├────────────┴────────────────────────┴───────────────┤
│  파일시스템  │  출력 콘솔  │  디버거                  │
└─────────────────────────────────────────────────────┘
```

### 핵심 용어

| 용어 | 설명 |
|------|------|
| **Scene** | 게임 오브젝트들의 묶음. `res://` 경로의 `.tscn` 파일 |
| **Node** | Scene을 구성하는 최소 단위. 모든 것이 Node |
| **Inspector** | 선택한 Node의 속성을 보고 편집하는 오른쪽 패널 |
| **res://** | 프로젝트 루트를 가리키는 Godot 전용 경로 |
| **F5** | 프로젝트 메인 씬 실행 |
| **F6** | 현재 열려있는 씬만 실행 |

### 에러가 났을 때
에디터 하단 **Output** 탭에 빨간 에러 메시지가 표시된다.
그 메시지를 그대로 복사해서 Claude에게 전달하면 된다.

```
예시 에러:
E 0:00:01:0342   player.gd:15 @ _ready(): 
  Node not found: "Camera" in path "."
```

이런 에러가 뜨면 → 전체 복사 → Claude에게 붙여넣기

## 실습: 프로젝트 파일 구조 확인

Claude가 앞으로 파일을 이 구조에 맞게 생성한다.
에디터 파일시스템 패널에서 다음 폴더들을 확인한다.

```
res://
├── scenes/
├── scripts/
├── assets/
└── docs/        ← 지금 읽고 있는 파일들
```

> **실습**: Godot 에디터를 열고 하단 FileSystem 패널에서
> `scenes/`, `scripts/` 폴더가 없으면 우클릭 → New Folder로 만들어두자.
> (이후 Claude가 이 경로에 파일을 직접 생성한다)
